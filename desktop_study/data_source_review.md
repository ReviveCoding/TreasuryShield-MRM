# Official data source review

Reviewed and updated 2026-09-27 after validating the acquired files. Exact file URLs, retrieval timestamps, periods, vintages, sizes, and hashes are in `data/manifests/raw_manifest.csv`; aggregate counts are in `artifacts/results.duckdb`.

| Source | Intended use | Current access and caveat |
|---|---|---|
| [New York Fed harmonized historical Call Reports](https://www.newyorkfed.org/research/banking_research/balance-sheets-income-statements) | Core bank panel | Acquired both ZIPs, dictionary, and README. Despite `Jan2026` in URL paths and an older README/page date range, the internal June 2026 Stata files contain 1959Q4–2026Q1 with 2,557,391 rows each. `date` is a Stata quarterly integer anchored at 1960Q1, not a timestamp. The commercial-bank 1984+ panel has 1,384,379 rows. |
| [FFIEC public bulk](https://cdr.ffiec.gov/public/PWS/DownloadBulkData.aspx) and [download help](https://cdr.ffiec.gov/public/HelpFiles/DownloadHelp.htm) | Enhanced modern panel and form-specific granularity | Public bulk access worked without credentials. Acquired all 38 quarterly ZIPs 2017Q1–2026Q2; 189,811 filer quarters with 031/041/051 type in POR metadata. The direct RCON5597 uninsured estimate covers only 17.1% overall; missingness varies by form and is not converted to zero. 161,780 quarters match the New York Fed Core Panel. |
| [FDIC BankFind Suite API](https://api.fdic.gov/banks/docs) | Institution IDs, histories, mergers, failures, optional SOD | Acquired 27,834 institution metadata rows, 185,483 FI-level history events from 19 paginated files, and 4,117 failure-list rows. Source pages can omit entirely empty columns; the parser fills those as missing. A missing bank-quarter is not a failure. |
| [Federal Reserve H.8](https://www.federalreserve.gov/releases/h8/about.htm) | System context and weekly shapes | Estimated weekly aggregate commercial-bank balance sheets; never bank-specific observations. |
| [FRED](https://fred.stlouisfed.org/) and [ALFRED real-time periods](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html) | Rates, curve, volatility, labor/activity, inflation, modern SOFR; vintage sensitivity | Acquired no-key current CSVs and 262 actual ALFRED vintage snapshots at quarter forecast origins. The FRED graph route silently ignored `vintage_date`; the separate ALFRED graph host returned genuine historical revisions. CFNAI vintage snapshots in that route begin 2012Q1. Revised current values remain separate from the vintage-aware panel. |
| [FR Y-9C form](https://www.federalreserve.gov/apps/reportingforms/Report/Index/FR_Y-9C), [Chicago historical files](https://www.chicagofed.org/banking/financial-institution-reports/bhc-data), and [NIC](https://www.ffiec.gov/npw/FinancialReport/FinancialDataDownload) | BHC external validation only | Acquired 81 official Chicago Fed CSVs 2001Q1–2021Q1 and parsed 93,374 consolidated BHC quarters. The modern NIC site returned a CAPTCHA to programmatic requests. BHCs are a distinct unit and remain separate from commercial banks. |
| [FDIC Summary of Deposits](https://api.fdic.gov/banks/docs) | Optional geographic concentration | Annual frequency and publication lag prohibit quarterly contemporaneous backfill. |

Storage decision: retain the 425 raw official files as the read-only snapshot `fbc0b7b5a2c46fbcc0b5` (1.827 GB compressed/stored, 5.981 GB summed uncompressed ZIP contents and other files), and use selected-column Parquet for analysis. The two source Stata files were extracted once into `data/interim/newyorkfed/` and are not raw. Initial free C: space was about 72.8 GB; free space was checked during acquisition.
